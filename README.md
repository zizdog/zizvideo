# Zizvideo

自托管的短视频 / 短剧应用：把你自己电脑上的视频目录扫进来，用浏览器上下滑着看。
**装一次、选个目录、打开网页就能看。**

## 一、安装（macOS）

```bash
curl -fsSL https://mirror.zizdog.com:8888/apps/zizvideo/install-zizvideo.sh | bash
```

装完打开 <http://127.0.0.1:7766>，首次访问是初始化页（建管理员账号）。

- **别写成 `| sudo bash`**：需要提权时脚本自己会问你要 sudo。
- 装成**系统服务**：开机自动运行，不用登录、也不用一直开着终端。
- 安装过程分 6 步讲给你听；失败会**自动回滚**，不会留下半截状态。
- 它会问你要不要给「完全磁盘访问」权限：**给一次**，外接盘 / 桌面 / 文稿 / 下载里的视频才能被扫到。
  不给也能用 —— `~/Movies` 里的视频不受影响。

## 二、使用（三步）

1. 打开 <http://127.0.0.1:7766> → **建一个管理员账号**（这就是你自己的账号）。
2. 后台 →「媒体允许根」→「浏览目录…」选中你放视频的文件夹 →「加为允许根」。
3. 后台 →「媒体库」→ 新建一个库指向该目录 → 点「扫描」。扫完回首页上下滑着看。

- 播放进度自动续播；右下角竖排按钮是收藏 / 点赞（管理员多一个删除）。
- **手机 / 平板**：和电脑连同一个 Wi-Fi，浏览器打开 `http://<电脑的局域网 IP>:7766`
  （默认只允许本机访问；要局域网访问就把监听地址改成 `0.0.0.0:7766`，见下）。
- 上传、剧场、用户、注册开关等都在**后台页面**；观看页只负责看。

## 三、升级 / 卸载

```bash
# 升级到最新版（重跑安装那条命令就行）
curl -fsSL https://mirror.zizdog.com:8888/apps/zizvideo/install-zizvideo.sh | bash

# 体检：只读，不改任何东西
curl -fsSL https://mirror.zizdog.com:8888/apps/zizvideo/install-zizvideo.sh | bash -s -- --verify

# 卸载：保留你的视频数据与配置
curl -fsSL https://mirror.zizdog.com:8888/apps/zizvideo/install-zizvideo.sh | bash -s -- --uninstall

# 卸载并删除数据（会二次确认）
curl -fsSL https://mirror.zizdog.com:8888/apps/zizvideo/install-zizvideo.sh | bash -s -- --purge
```

- 数据默认在 **`~/zizvideo`**（数据库 + 封面 + 配置）：**备份就是把这个目录拷走**；卸载默认不动它。
- 其它常用参数（接在上面命令的 `--` 后面）：`--listen 0.0.0.0:7766` 换监听地址、
  `--data-dir /外置盘/zizvideo` 换数据目录、`--dry-run` 只打印会做什么、`--help` 看全部。

## 四、常见问题

- **有些视频没被扫到**：目录不在「媒体允许根」里、外接盘没挂载，或没给「完全磁盘访问」。
  先看后台媒体库的报错，再跑一次上面的体检命令。
- **打不开 / 提示端口被占用**：`7766` 被别的程序占用了（例如面板托管的 zizvideo）。
  **面板托管和独立部署只能选一个**；想两个一起用就换端口：安装时加 `--listen 127.0.0.1:7767`。
- **面板托管还是独立部署**：二选一。面板里装的就让面板管（更新、卸载都在面板里）；
  不想装面板就用本文第一条命令。
- **某些视频只出声不出画**：这台浏览器解不了 HEVC，等后续版本的内置转码。
- **走反向代理上传大文件失败**：把请求体上限放开（nginx：`client_max_body_size 0;`）。
