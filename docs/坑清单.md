# zizvideo 坑清单（只放"删了会再踩"的结论）

格式：现象 → 根因 → 修法 → 门禁/判据。过期条目直接删，不做博物馆。

1. **网页端能删掉任意路径的文件**：删文件只信请求里的 path。
   → 必须先 `media.ValidateMediaFile(允许根, 库根, path)`，删完 `os.Stat` 回读；
   文件删不掉就**不许**删记录（否则"记录没了文件还在"是谎报）。门禁：`internal/api/media_delete_test.go`。
2. **同版本换字节重发**：产物 sha256 变了，"已装 0.1.2" 与"新装 0.1.2"不是同一份东西，
   面板的"可更新"判断也会错乱。→ 改代码就 bump 版本；`publish-mirror.sh` 默认拒绝覆盖同版本。
3. **`$VAR` 紧跟中文时 shell 报 unbound variable**：macOS 自带 bash 3.2 会把多字节字符算进变量名
   （`$VERSION（` → 变量名 `VERSION（`）。→ 中文前一律写 `${VAR}`。判据：脚本用 `/bin/bash` 跑一遍。
4. **镜像盘写不进去**：`/Volumes/ZPMirror/**` 只有 mini 的面板进程有 TCC 授权，本机/sudo/SSH 都是
   `Operation not permitted`。→ 发布走 mini 面板 HTTP 接口（`tools/publish-mirror.sh`），别试 rsync。
5. **`-buildvcs=false` 不能去掉**：Go 默认把 VCS 状态写进二进制，sha256 会随提交漂，
   镜像索引写死的校验值就对不上了。
6. **未签名的二进制每次升级都要重新授权**：macOS TCC 对 adhoc 签名按 `cdhash` 判定，一变就失效。
   → 固定自签证书 + identifier `com.zizvideo.server`（`tools/codesign-release.sh`）。
7. **前端语法错误 = 整页白屏且不给行号**：`node --check` 会放过（对象字面量少个 `}`）。
   → `make check` 用 acorn 真解析器，**缺 acorn 直接失败**，不许"缺了就跳过"。
8. **管理入口放在观看页**（用户 2026-09-22 点名）：剧场是看剧的地方，管理必须收进后台
   「剧场」页签。判据：`internal/api/frontend_assets_test.go` 的 `TestSeriesManagementOnlyInBackend`
   （观看面不许出现管理模块/admin 接口）。
9. **开关开了但前端没入口**（注册开关实例）：后端有开关 + 公开接口，前端却没有页面，
   公开状态接口也没透出这个开关 ⇒ 用户看到"开了注册，登录页没入口"。
   → 开关类功能必须同时给：公开状态字段 + 前端入口 + 后端拦截（三层都测）。
10. **子代理/测试不许动真机系统状态**：钥匙串信任、`/Library/LaunchDaemons`、`sudo`、
    `launchctl bootstrap system` 只能用假命令（`ZV_FAKE_*`）验证；真跑了却报"未真跑"= 谎报。
