# 手机上装 zizvideo 客户端（给使用者看）

## 一、装
1. 把 `app-release.apk` 传到手机（数据线 / 微信文件传输 / 网盘都行），点它安装。
   系统若提示"未知来源"，允许一次即可。
2. 打开 App → 填**服务器地址**（如 `192.168.1.9:7766`，不用写 `http://`）、**用户名**、**口令** → 登录。
   - 地址填错会当场告诉你"连不上"，不会转到别的页面。
   - 登录过一次之后，**以后打开不用再输**（会话过期才会再问）。
   - 服务器还没建管理员时，App 会直接进网页让你初始化。
3. 建议顺手点一下登录页上的「**允许后台运行**」（系统会弹一次窗）—— 这是"听着听着没了"最常见的原因。
   国产 ROM 还要在「设置 → 应用 → zizvideo」里允许**自启动/后台运行**，这个只能手动。

## 二、用
- 界面就是服务器上的那套网页，操作一模一样：首页刷视频、剧场、收藏/历史/稍后再看、搜索、后台管理。
- **退到后台/锁屏会继续放**：网页这边一退到后台，播放会交给原生播放器（通知栏/锁屏都能控制）。
  回到 App 会自动接着放，不会两路声音。
- 从「收藏/历史/稍后再看/搜索结果」点开的是**原生播放页**：播放/暂停、上下一条、进度、❤ 收藏、👍 喜欢、🕒 稍后再看。
- 长按桌面图标有「**听首页**」：不打开网页，直接后台听首页队列。
- 播放过的位置会**续播**（没看完的话）。

## 三、自己验三件事（可选）
手机连电脑、开 USB 调试后，在电脑上跑：
```bash
# 1) 是不是手机硬件解码（软解会明显更费电）
adb shell dumpsys media.metrics | tr ',' '\n' | grep -o "android.media.mediacodec.codec=[a-zA-Z0-9._-]*" | sort | uniq -c | sort -rn
#   c2.android.* 开头的 = 软解；c2.qti.* / c2.mtk.* / c2.exynos.* / OMX.* = 手机硬件解码

# 2) 后台有没有被系统回收（播放中执行，应看到 ExoPlayer 的 partial wakelock）
adb shell dumpsys power | grep -i "ExoPlayer:WakeLockManager"

# 3) 通知栏控制（等价耳机线控）
adb shell input keyevent 127   # 暂停 → 再查状态应为 PAUSED
adb shell input keyevent 126   # 播放 → 应为 PLAYING
```

## 四、常见问题
| 现象 | 原因 / 怎么办 |
|---|---|
| 提示"连不上服务器" | 地址或端口不对；手机和服务器不在同一网络；服务器没开 |
| 提示"登录过期了，请重新登录" | 会话过期，重新输一次口令即可 |
| 提示"文件不在了（可能已改名或移动）" | 服务器上这个文件被改名/移走了，到后台「媒体」页清理这条记录或重扫库 |
| 退到后台一会儿就停 | 没允许后台运行：App 里点「允许后台运行」，再去系统设置允许自启动/后台 |
| 只有画面没有声音 | 网页播放器默认静音自动播：点右侧图标栏里的喇叭 |
| 视频很费电/发热 | 查上面第 1 条：若显示 `c2.android.*` 说明这台手机在软解，换台机器或降到 720p 素材 |
